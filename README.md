# Little Lemon Web Application

A Django REST Framework web application for the Little Lemon restaurant.

This project was developed as part of the Meta Back-End Developer Capstone on Coursera.

## Technologies

- Python 3.11
- Django 5.2
- Django REST Framework
- MySQL 8.4
- Djoser
- Token Authentication
- HTML
- CSS
- JavaScript

## Features

- Django static HTML homepage
- MySQL database integration
- Restaurant menu API
- Category API
- Table booking API
- User registration
- Token authentication
- Django Admin
- API filtering
- API searching
- API ordering
- API pagination
- Input validation
- Unit tests
- Insomnia-compatible REST endpoints
